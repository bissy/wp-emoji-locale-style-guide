# WordPress Emoji Locale (`art-xemoji`): Style Reference

A community style reference for translating WordPress into the Emoji locale.

🌐 https://translate.wordpress.org/locale/art-xemoji/default/

## Why this exists

The [official glossary](https://translate.wordpress.org/locale/art-xemoji/default/glossary/)
has 27 entries. Everything else (how to handle grammar, numbers, questions, placeholders,
and compound concepts) has to be inferred from existing translations.

`art-xemoji` is an experimental locale with no active maintainer (most glossary entries date
from 2016), which means conventions drift. Core currently sits at ~3% translated with a few
hundred strings waiting for review, and existing translations follow at least two
incompatible styles.

This repo is an attempt to write the conventions down so contributors can stay consistent.

## Status

**Draft, open for discussion.** Nothing here is official. It's a working document based on
the official glossary plus analysis of existing translations.

The [Open questions](STYLE-REFERENCE.md#8-open-questions-would-love-your-input) section lists
the conventions that are still guesses. Input very welcome.

## Contributing

Corrections, additions, and disagreements are all useful.

- **Open an issue** to question a convention or raise something the reference doesn't cover
- **Open a pull request** to propose a change
- Existing translations are the strongest evidence, so please link to any you cite

If you translate into `art-xemoji` and follow (or deliberately diverge from) something here,
that's worth recording either way.
